# 정수빈 포트폴리오 · 아이스 블루

## 파일 구성
- index.html: 웹페이지 내용
- style.css: 색상, 레이아웃, 반응형 및 글래스 효과
- script.js: 폴리곤 메쉬 인터랙션, 달력 미리보기

## 열기
index.html을 브라우저에서 열면 미리 볼 수 있습니다. 편집할 때는 세 파일을 같은 폴더에 두세요.

## 현재 미리보기 항목
- 히어로의 저폴리곤 메쉬는 실제 모델 파일로 교체하기 전의 캔버스 미리보기입니다.
- GitHub 기여 달력은 데모 데이터입니다. 실제 기여 내역에는 GitHub 사용자명 연결이 필요합니다.
- 이름은 정수빈으로 설정되어 있고, 연락처와 경력/프로젝트 세부 내용은 예시입니다.
