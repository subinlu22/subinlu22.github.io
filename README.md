## 사이트에 들어간 기능
- **히어로 와이어프레임** — 직접 모델링한 군용 차량 와이어프레임 위로 빛이 선을 따라 흐르는 효과 (Canvas)
- **궤도 키워드** — 키워드 칩이 차 주위를 행성 궤도처럼 회전
- **렌더 ↔ 와이어 비교 슬라이더** — 3D 작업의 최종 렌더와 와이어프레임을 드래그로 비교
- **커밋 기록 연동** — GitHub 기여 기록을 받아와 달력으로 표시
- 반응형 레이아웃 (모바일 대응), 동작 줄이기 설정 대응
